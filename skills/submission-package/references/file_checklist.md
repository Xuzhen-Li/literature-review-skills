## Upload order

Use the order on the journal's author page when it lists one. Otherwise:

1. Cover letter
2. Title page
3. Manuscript with line numbers
4. Figure files, one per ledger id, in id order
5. Permissions receipts for every reused or adapted item
6. Declarations, if the journal asks for them as a separate file
7. Supplementary evidence table and search strings

Do not upload a file that still contains `[VERIFY]`, `[TITLE]`, or `PENDING`.
