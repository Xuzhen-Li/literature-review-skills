# Tone

Write to the editor, about the comment, in plain sentences.

- Thank the person for the specific point once. Do not open every reply with the same compliment.
- Answer the request in the first sentence. The second sentence says what you did or what you did not do.
- Quote the reviewer only as far as you need to identify the point. Do not parody the comment.
- If you disagree, say `We have not changed this sentence because ...` and give the evidence ID. Do not write that the reviewer is wrong, confused, or hostile.
- If you agree and the file changed, the revision phrase and the page and line are in that same paragraph. A promise with no location is not a reply.
- Do not apologize for the existence of the paper. Apologize for a concrete error you corrected, and say what the correction was.
- Keep each reply shorter than the comment unless the comment asked for new text.

COPE's expectation is that the discussion stays inside the journal's review system. Do not email a reviewer directly. Publication ethics overview: https://publicationethics.org/
