# Removing template ("AI") prose

The aim is natural, clear, accurate scientific English that a researcher outside the subfield can follow. Never introduce errors, slang, casual tone, or vagueness to look less machine-written.

## Patterns to find

| Pattern | Example | Fix |
|---------|---------|-----|
| Uniform sentence length and rhythm | five 20-word sentences in a row | Vary: merge two related points, keep a short sentence for the key judgement |
| Connector overuse | However, Moreover, Furthermore, Notably, Additionally at sentence starts | Link by cause, condition, time, or design ("Under flooding, …", "Because …", "Over longer incubations …"); delete connectors that add nothing |
| Empty praise phrases | plays a crucial role; provides valuable insights; sheds light on; paves the way; a growing body of evidence | Say what it does: "controls the release of …", "showed that …" |
| One sentence per paper | "Smith (2019) found… Lee (2020) found…" | Group papers behind one judgement and cite them together |
| Runs of short sentences | "X increased. Y fell. Z was stable." | Combine into a sentence that states the relation |
| Repeated caveats | "cannot prove", "cannot be extrapolated", "should be interpreted with caution" in every paragraph | State a limitation once, where it changes the conclusion |
| Abstract noun stacks | "the soil moisture-dependent contaminant mobilization enhancement effect" | Use a subject and a verb: "wetter soil mobilized more of the contaminant" |
| Recap endings | section ends by restating its paragraphs | End with the judgement the section supports |
| Template triplets and parallelism | "not only…, but also…, and furthermore…"; three adjectives every time | Keep only the items that carry information |

## Rewrite principles

- Concrete subjects and specific verbs.
- Explain the phenomenon before naming the term.
- Merge citations that support the same point.
- Let sentence length vary with the content.
- Build transitions from causation, conditions, time scale, and study design.
- State each limitation once, where it matters.
- Delete adjectives and set phrases that add no information.
- Keep technical precision; do not soften a claim the evidence supports or strengthen one it does not.

## Quick self-check after a rewrite

1. Count sentence-initial However/Moreover/Furthermore/Notably/Additionally per page; more than one or two is a flag.
2. Search for the empty phrases above.
3. Read the first and last sentence of each paragraph: the first should be a claim, the last a judgement.
4. Search for repeated caveat wording.
