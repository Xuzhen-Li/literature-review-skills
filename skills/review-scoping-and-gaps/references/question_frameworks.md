# Question frameworks

Use one framework. Record every element. An element the user has not decided is `[VERIFY]`, not a guess.

## systematic — PICO or PEO

Intervention questions use PICO: Population, Intervention, Comparator, Outcome.

Exposure questions use PEO: Population, Exposure, Outcome. The design spec's "PEO" is this triple. Add a comparator when the user has one; do not invent a control group.

## qualitative systematic — SPIDER

Sample, Phenomenon of Interest, Design, Evaluation, Research type.

## scoping — PCC

Population, Concept, Context. This is the JBI scoping-review frame. The question is about the extent and nature of the evidence, not a single pooled effect. Report later with PRISMA-ScR (https://www.prisma-statement.org/).

## narrative

Write the theme, the boundary (what is in, what is out), and the audience. Do not force PICO onto a narrative review. Still name the boundary so the search skill has concepts.

## umbrella

The unit of inclusion is a systematic review (or a scoping review, if the user says so). Record: the question the reviews address, the review designs that count, and whether primary studies are out of scope. They are out of scope unless the user explicitly includes them.

## Handoff to the search skill

Turn each filled element into one concept row: concept name, include terms, exclude terms. Leave synonyms to `search-strategy-builder`.
