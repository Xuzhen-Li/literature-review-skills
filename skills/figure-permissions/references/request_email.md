# Permission request the user sends

Save as `<project>/12-permissions/emails/Fig-2.md`. Replace every bracket. The agent does not send this message and does not pay a fee.

```
To: permissions address printed on the version-of-record page
Subject: Permission to reuse Figure N from Author et al., Year, in a review article

Dear Permissions editor,

I am preparing a review article, "[TITLE]", for submission to [JOURNAL].
I ask permission to reuse the following material:

- Source: Author et al., Year, Journal, volume, pages, DOI
- Item: Figure N (or Table N)
- Use: one figure in a scholarly review, print and electronic, in that one article
- Changes: none (reuse) / the following changes (adaptation): [WHAT CHANGES]

Please tell me the credit line you require and any fee. I will not use the
figure until I have your written grant or a RightsLink receipt.

Corresponding author: [NAME]
Email: [EMAIL]
```

If the article page uses RightsLink (Copyright Clearance Center, https://www.copyright.com/), the user opens the button on that page instead of this email. On the form, choose reuse in a journal and this figure. Choose both print and electronic when the journal publishes both. Do not guess a print-run number; if the form requires one, stop and ask the user. Save the receipt PDF to `12-permissions/grants/`.

Do not attach the figure file from a shadow library. Linking the DOI is enough for the publisher to identify the source.
