# Credit lines

Use one of these shapes in the ledger `caption_credit` cell and in the manuscript caption. Fill the brackets from the evidence row and from the license page or the receipt. Do not invent a license number.

Original:

```
Created for this review.
```

Reused under a Creative Commons license that allows it (the deed URL must be the one you opened, for example https://creativecommons.org/licenses/by/4.0/):

```
Reproduced from Author et al., Year, Journal, volume, figure number, under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
```

Adapted under that same kind of license:

```
Adapted from Author et al., Year, Journal, volume, figure number, under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/); changes: [what changed].
```

Reused with a publisher grant. Write this only after the receipt is filed:

```
Reproduced with permission from Author et al., Year, Publisher; permission [license number from the receipt].
```

Adapted with a publisher grant, only after the receipt is filed:

```
Adapted with permission from Author et al., Year, Publisher; permission [license number from the receipt]; changes: [what changed].
```

CC0 or public domain still gets a scholarly credit, even though attribution is not a license condition:

```
Reproduced from Author et al., Year, Journal, volume, figure number (CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/).
```

If the target journal confirms STM clearance in writing, say so and still name the source. Do not use that sentence without the journal's note or a receipt in `12-permissions/grants/`:

```
Reproduced from Author et al., Year, Journal, volume, figure number, with STM Permissions Guidelines clearance confirmed by [journal] on YYYY-MM-DD.
```

`PENDING` is the cell value until one of the sentences above is true. It is not a caption.
