# Official pages for journal facts

Open these yourself. A search snippet is not a check. Date every check in the shortlist.

| Fact | Where to read it |
| --- | --- |
| Author guidelines, article types, word limit, reference style, APC | The journal's own "for authors" or "submit" page on the publisher's site |
| DOAJ listing | https://doaj.org/ |
| MEDLINE / NLM catalog | https://www.ncbi.nlm.nih.gov/nlmcatalog/ |
| Web of Science Master Journal List | https://mjl.clarivate.com/home |
| Journal Citation Reports (impact factor; access-controlled) | https://jcr.clarivate.com/ |
| Scopus source list | https://www.elsevier.com/products/scopus/content |
| ICMJE recommendations, when the journal says it follows them | https://www.icmje.org/recommendations/ |

Do not use a journal's impact factor, quartile, or review time from a ranking site, a university library guide, or a social network. If the official page does not state the number, write `[VERIFY]` or `not stated`.
